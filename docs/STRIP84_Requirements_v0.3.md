# STRIP / 84 — 產品需求與規格

> **v0.3 · 2026-11-07 · 概念設計／選型中**  
> 依據上一版 `STRIP84_Product_Design.html` 的84鍵資料延伸，新增程式繪製的分解、俯視與側視圖。本文件不是可直接加工或投產的工程包。

## 1. 產品定義與目前狀態

一台75%概念配列的84鍵青軸機械鍵盤，具備獨立實體F1～F12、全寬圖形Touch Bar、側螢幕、旋鈕、USB-C與BLE，由同一顆ESP32控制。

Touch Bar必須能顯示可變圖案、文字、滑桿與狀態列。可接受單色或彩色圖形顯示；不接受固定背光圖示、純電容條或拼接螢幕作為同等替代。

**總預算要求仍為NT$3,000，完整規格尚未達成此預算。** 不含全寬Touch Bar的84鍵原型估算為NT$2,908，包含未確認目標價。合格全寬觸控總成、相容驅動與額外運稅尚無確定報價。

| ID | 需求 | 可驗收行為 |

### 本版採用的設計選擇

- 75%概念配列、84鍵，含方向與導覽鍵，不含數字鍵盤區。
- 定位板＋手工焊接矩陣；熱插拔與客製全尺寸PCB不列為必要。
- USB 5V供電，不含鋰電池；切到BLE-B時可繼續由USB-A供電。
- 拔線後獨立BLE使用需另備合適5V電源，不假設免費附送電池。
- 兩台都用BLE為額外多連線需求，尚未納入本版驗證基準。
- 圖面鍵帽配色只是外觀提案；顯示色彩也尚未凍結。

## 4. 機構尺寸與座標

X由左向右、Y由後緣Touch Bar側往前緣、Z自桌面向上；單位mm。

### 4.1 平面配置

| 部位 | 設計目標 | 狀態 |
|---|---|---|
| 機身 | 365寬 × 170深 | 可能依面板外形調整 |
| 主鍵區 | X=53，Y=44；304.8 × 114.3 | 16u × 6u；鍵距19.05 |
| 左側控制區 | X=8，Y=44；約40 × 114.3 | 旋鈕、側螢幕與內部控制板 |
| 主鍵區與左區間距 | 約5 | X=48至53 |
| Touch Bar有效區 | X=8，Y=8；349 × 22 | 尚無合格可採購型號 |
| 上方蓋板示意 | X=4，Y=4；357 × 30 | 僅渲染包絡，不是現成面板尺寸 |
| 有效顯示區左右留邊 | 約8／側 | 仍需容納玻璃、固定、FPC |
| 側螢幕 | 1.69吋，240×280 | 模組外框與固定孔待實物確認 |
| USB-C開口 | 後側偏左 | 示意位置，需配合主控原生USB口 |

**全寬指有效顯示區。** 不能用整片蓋板遮住數片小屏，也不能把外形300mm、有效長度282mm的面板當成本版349mm目標。

## 6. 電控與原型接線

| 元件 | 基準規格／職責 |
|---|---|
| 主控 | ESP32-S3 N16R8：16MB Flash、8MB PSRAM |
| 矩陣 | 7×12＝84鍵，每鍵一顆二極體 |
| I/O擴充 | MCP23017×2，I²C位址0x20／0x21 |
| 側屏 | 1.69吋、240×280、ST7789V系列SPI模組 |
| 旋鈕 | EC11 A/B相＋按壓 |
| Touch Bar | 像素式圖形面板＋連續座標觸控；料號TBD |
| 顯示驅動 | 依面板選擇；S3沒有原生MIPI DSI |

一顆ESP32-S3管理全機狀態、按鍵路由、GUI與通訊。周邊IC可以協助掃描、觸控、顯示與供電，不以第二顆應用主控分別執行兩套邏輯。

### 6.1 原型腳位表

沿用v0.2；核對實際開發板原理圖後才能接線。此表不是全寬版最終接腳表。

| 功能 | 接腳／連接 |
|---|---|
| 原生USB D−／D+ | GPIO19／GPIO20，使用開發板原生USB口 |
| I²C SDA／SCL | GPIO8／GPIO9，3.3V邏輯 |
| 側TFT MOSI／SCLK | GPIO11／GPIO12 |
| 側TFT DC／CS／RST | GPIO13／GPIO14／GPIO15 |
| 側TFT BL | GPIO16可作PWM訊號；不能假設可直接供背光負載 |
| EC11 A／B／SW | GPIO4／GPIO5／GPIO6 |
| MCP #0 | 0x20：GPA0～6→R0～R6，GPB0～7→C0～C7 |
| MCP #1 | 0x21：GPA0～3→C8～C11 |
| 全寬顯示／觸控 | 待面板介面、電壓與GPIO盤點後分配 |

接線條件：

- I²C上拉需納入模組自帶電阻；位址腳與RESET不可懸空。
- 每顆MCP旁預留100nF去耦，入口另放適當儲能電容。
- 掃描時僅目前row輸出低，其他row高阻；column啟用上拉。
- 二極體方向為column → 開關 → 二極體 → row，**條紋陰極朝row**。
- 背光與面板電源按實際規格設計，不直接套用GPIO供電能力。
- 若顯示橋接需要大量RGB接腳，須重新分配腳位並驗證頻寬。

## 7. Touch Bar圖形與觸控

| 元件 | 必要行為 |
|---|---|
| 圖示按鈕 | 圖案／標籤可依App、圖層或電腦指令變更 |
| 滑桿 | 顯示軌道、滑塊、數值，支援點選與連續拖曳 |
| 狀態列 | 可更新文字、圖示、連線／工作狀態 |
| 進度條 | 由主機數值或本機狀態更新 |
| 頁面／圖層 | 不同版面可保存，切換不影響實體F排存在 |

觸控流程：

1. 讀取連續X/Y座標並轉換到UI座標。
2. 按下時命中元件，鎖定該次觸控的元件與主機目標。
3. 拖出元件邊界時仍維持原拖曳，數值限制於合法範圍。
4. 放開／取消時終止拖曳並送最後狀態。
5. 切換主機時取消舊手勢與連發，等待手指放開後才能對新主機開始操作。
6. 至少單點觸控；多點為可選項，選型前不宣稱支援。

更新與排程：

- 日常只傳數值、文字或圖示ID，由鍵盤繪圖；圖示可預存Flash。
- 不把BLE當全畫面串流，顯示刷新不得阻塞鍵盤事件。
- 實際更新率與回饋延遲量測後定稿，不預先宣稱60fps。
- video-mode面板仍需持續符合掃描時序；少改UI不代表面板頻寬同步降低。
- 單色圖形OLED／LCD也可實現上述介面，前提是全寬尺寸與驅動可取得。

## 8. 雙裝置、旋鈕與供電

| 目標 | 連線 | 按鍵 | 雙向資料 |
|---|---|---|---|
| A | USB-C | USB HID鍵盤／媒體鍵 | CDC或等效資料通道 |
| B | BLE | HID over GATT | 自訂GATT服務 |

兩條連線保持存在，但只有目前選中目標收到操作。USB-A可在操作BLE-B時持續供電。

EC11一完整格切A／B；長按約2秒進BLE配對是本版設計選擇。新目標離線時顯示離線，不把輸入改送別處。

切換順序：

1. 對舊目標釋放一般鍵、修飾鍵與媒體鍵。
2. 取消未完成巨集、連發與觸控拖曳。
3. 切路由並載入新裝置UI。
4. 切換時按住的鍵需放開再按，才送往新目標。
5. 量測已連線、睡眠、斷線及重連情境後，再訂切換延遲指標。

「立即」的方向是持續連線後切路由，不是每次重新配對；尚無實機延遲數據。

供電基準為USB 5V，邏輯3.3V。全寬顯示總成的穩壓、背光、峰值電流與USB供電能力必須獨立核對；不可把未知面板直接掛在開發板穩壓器上。本版不含電池及充電系統。

## 9. 可編程與電腦端

不需電腦常駐程式的功能：

- 一般打字、F1～F12、媒體鍵。
- 本機圖層、組合鍵與延遲巨集。
- 按鍵／旋鈕／觸控觸發本機UI。
- 載入已保存的裝置設定。

需要電腦程式的功能：

- 偵測前景App並切換Touch Bar版面。
- 提供CPU、編譯、播放與專案狀態。
- 把具名action對應到使用者設定的程式或命令。
- 上傳、修改與同步設定。

USB與BLE共用訊息語意。USB可用換行分隔JSON；BLE按MTU分段後重組，帶ID與ACK。圖示資源優先預載。

```json
{
  "v": 1,
  "id": 42,
  "op": "ui.patch",
  "profile": "usb-a",
  "widgets": {
    "volume": {"value": 64},
    "build": {"value": 42, "state": "running"},
    "action1": {"icon": "terminal", "text": "Terminal"}
  }
}
```

鍵盤送出的具名動作例如 `project.build`。以上是規格草案，不是已完成的韌體或常駐程式。

## 11. 製作與驗收

| 階段 | 工作 | 通過條件 |
|---|---|---|
| 0 | 面板／觸控／驅動選型與詢價 | 尺寸、功能、相容性及總預算均有依據 |
| 1 | S3原生USB與BLE HID | A／B各自可輸入，並能持續雙連線 |
| 2 | EC11與路由 | 反覆切換、按住修飾鍵切換也不卡鍵 |
| 3 | 2×2矩陣試片 | 二極體方向、去抖與組合鍵正確 |
| 4 | 擴充84鍵 | 所有鍵正確，F1～F12直接輸出 |
| 5 | 側屏與資料通道 | 主機／按鍵／圖層可更新畫面 |
| 6 | 全寬圖形觸控 | 可變圖案、連續滑桿、狀態列與動作正常 |
| 7 | 機構與電源驗證 | 無干涉，最大負載不掉電／重啟 |
| 8 | 外殼加工 | 取得實際尺寸、公差與加工價後下單 |

驗收清單：

- [ ] 實體84鍵及F1～F12正確，皆為機械青軸。
- [ ] Touch Bar全寬無拼接，為可重畫像素圖形。
- [ ] 圖案、文字、滑桿、狀態列均可更新。
- [ ] 拖出元件及切主機時，手勢可以正確結束／取消。
- [ ] 同一ESP32控制兩片顯示及全部輸入／連線。
- [ ] USB-A與BLE-B保持連線，旋鈕切換不重配對。
- [ ] 睡眠、斷線、切換及重連均不造成卡鍵。
- [ ] 最大顯示負載下打字穩定，量測輸入及觸控回饋。
- [ ] 量測峰值電流、壓降、溫度，完成機構／接頭／天線淨空檢查。
- [ ] 所有必要零件及運費有確認價，合計不超過NT$3,000。
